### Prévisualisation
Ouvrir `preview/WANDER_PREVISUALISATION_INTEGRALE.html` dans un navigateur moderne (Chrome/Edge). L'interface permet de passer entre les pages grâce au menu Univers. Le formulaire **n'envoie aucun message** dans cette version autonome.

### Démarrer le site en développement
Avec Node.js et npm sur votre ordinateur :
```bash
npm ci
cp .env.example .env.local
npm run dev
```
Par défaut : `http://localhost:3000`.
